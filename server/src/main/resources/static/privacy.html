家庭共享 隐私政策

应用名称：家庭共享  |  应用包名：com.family.share  |  更新日期：2026年8月27日

本隐私政策由「家庭共享」App（以下简称“本应用”）的开发者（以下简称“我们”）制定并发布。本应用是一款仅面向家庭成员的自用位置共享工具。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。请在使用本应用前仔细阅读本政策。

一、我们收集哪些信息

  • 位置信息：精确/粗略经纬度（GCJ-02 坐标系）。用于在地图上展示您与家人的位置。
  • 粗略地址：省、市、区（县）、街道等地址信息，用于在成员详情页展示。
  • 设备标识：本应用首次启动时生成并保存在本机的唯一设备 ID（UUID），用于标识您的设备。
  • 设备信息：电池电量、网络类型（移动网络/无线网络）及当前连接的无线网络名称（SSID），用于在成员详情页展示设备状态。
  • 您主动提供的信息：昵称、头像图片，以及您通过“反馈/Bug”功能主动提交的文字内容。

二、我们如何使用这些信息

  • 用于家庭成员之间在地图上实时查看彼此位置、轨迹展示、一键刷新与响铃查找手机。
  • 用于在成员列表中展示电量、网络、地址等信息。
  • 用于实现应用内更新、消息通知等功能。

您的信息和位置，仅对您通过 6 位家庭码加入的家庭成员可见，不会向与该家庭无关的第三方展示。

三、第三方 SDK

本应用使用高德地图 / 高德定位 SDK（运营方：高德软件有限公司），用于地图展示与定位。该 SDK 会收集您的设备信息、网络状态及位置信息，其收集与使用遵循高德的隐私政策。高德隐私政策：https://lbs.amap.com/pages/privacy。

四、信息的存储

  • 您的位置、轨迹、家庭及成员信息存储于开发者自建的服务器（your-server.example.com，部署于中国大陆）。
  • 头像图片与您反馈的内容以文件形式存储于该服务器。
  • 我们仅在实现上述功能所必需的范围内保存您的信息，并按需清理历史位置数据（轨迹最多保留最近 300 个点）。

五、信息的共享、转让与公开披露

  • 除向您加入的家庭成员展示外，我们不会向任何第三方出售、出租或共享您的个人信息。
  • 除非法律法规要求或司法机关、行政机关依法提出要求，我们不会公开披露您的个人信息。

六、您的权利

  • 查询：您可在 App 内查看自己与家人的展示信息。
  • 更正：您可在 App 内修改昵称、上传或更换头像。
  • 删除：您可退出家庭，或由创建者将您移出家庭，以停止位置共享并删除相关数据。
  • 撤回同意：您可在系统设置中关闭定位、通知等权限，或卸载本应用以停止信息收集。
  • 注销 / 删除账号：本应用无传统账号体系；退出家庭即从服务器删除您的位置与相关数据。如您希望彻底删除，请按第九节联系我们。

关于权利的具体行使方式，请一并阅读《个人信息保护权利说明》。

七、未成年人保护

本应用面向家庭场景，未成年人应在监护人指导下使用，并应由监护人阅读并同意本政策。

八、信息安全与政策更新

  • 我们通过访问口令等安全措施保护服务器数据。
  • 本政策可能适时更新，更新后将在本页面公布，更新日期见页首。
