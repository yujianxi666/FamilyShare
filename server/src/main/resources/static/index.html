常见问题

如何加入家庭？

输入家人分享的 6 位家庭码提交申请，等待群主同意后即可看到彼此位置。

会一直上报位置吗？

默认约每 30 分钟向服务器上报一次；家人查看你时会立即上报一次。开启「下线模式」后可暂停上报。

我的位置安全吗？

数据存储在自建服务器，仅家庭成员可见，不在任何公共平台共享。详见《隐私政策》。

支持哪些设备？

当前支持 Android 设备，可在华为应用市场获取。

可以自建服务器吗？

可以。本项目客户端与服务端均已开源，欢迎自行部署；如有需要，也可联系作者提供公共服务器。
